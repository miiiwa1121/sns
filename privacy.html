プライバシーポリシー

「ついていくのが精一杯」の運営ツール（OmniPulse AI Studio、以下「本ツール」）における、Google アカウントおよび YouTube のデータの取り扱いを説明します。

1. 利用者

本ツールは運営者本人のみが使用します。第三者のアカウントは対象としません。

2. 取得するデータと利用目的

運営者が YouTube チャンネルへのアクセスを許可した場合に限り、次の目的でのみ利用します。

  • 動画のアップロード（YouTube Data API）
  • 投稿した動画の再生数・高評価数・コメント数・視聴維持率などの確認（YouTube Data API / YouTube Analytics API）

3. データの保管

取得したデータと認証情報は、運営者のコンピュータ内にのみ保存します。外部のサーバーには送信しません。

4. 第三者への提供

取得したデータを第三者に提供・販売・共有することはありません。広告目的での利用もしません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に準拠します。

6. アクセス許可の取り消し

運営者は Google アカウントの権限設定から、いつでも本ツールのアクセスを取り消せます。
