# OmniPulse Studio

AI・IT の最新トレンドを扱うショート動画チャンネル「ついていくのが精一杯」を、エージェント（Claude Code）と分担して運用するための仕組み。リサーチ → 台本 → 動画制作 → 承認 → 配信 → 計測 → 分析を回す。

- 管理画面: `npm run dev` → http://127.0.0.1:3001（使い方は画面の「使い方」）
- エージェント CLI: `npm run -s agent -- status`（手順は [docs/operations/agent-runbook.md](docs/operations/agent-runbook.md)）
- ドキュメント: [docs/](docs/README.md)
