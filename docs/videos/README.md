# 動画の絵コンテ一覧 (videos)

制作した動画ごとの絵コンテ（構成の記録）。`npm run agent -- produce` を実行すると自動で作成・更新される（手動では `storyboard <projectId>`）。

各ファイルには、行ごとの時間・場面・マスコットの表情・字幕・読み上げ文と、全行のコマを並べた画像、出典、投稿先を記録する。テンプレート自体の設計は [../architecture/video-template.md](../architecture/video-template.md) を参照。
