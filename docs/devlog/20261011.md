## AI とモデルの選択を「使えるものだけのプルダウン」にする
- 指摘（ユーザー）: Opus 5.5 しか選べない／選べない選択肢は出さない。
  - 原因: モデルの欄を「入力欄 + 候補（datalist）」にしていたため、ブラウザが今の値（claude-opus-5-5）に合う候補しか出さなかった。キーのない API も「（未設定）」付きで AI の選択肢に出していた。
- Claude Code で使えるモデルを1回ずつ呼んで確かめた: `claude-opus-5-5` / `claude-sonnet-5-5` / `claude-haiku-5-5` は動く（後ろの2つは「unrecognized_model」と出るが、そのモデルで答える）。別名 `sonnet` / `haiku` は Sonnet 5・Haiku 4.5 になる。`claude-fable-5-1` は claude.ai の利用枠がなく使えない。→ Opus 5.5 / Sonnet 5.5 / Haiku 5.5 の3つだけ出す。
- 実装: `purposeChoices`（今使える AI と、AI ごとの選べるモデル・既定・今の値）を作り、AI 連携の表とチャット欄の両方で使う。どちらもプルダウン。AI を変えるとモデルはその AI の既定に。API のモデル一覧はキーがあるときだけ取り、10分覚えておく（チャットの画面は数秒ごとに読み直すため）。保存のときも、使える AI と選択肢にあるモデルかを確かめる（`validateAssignment`）。
- 確認: ヘッドレス Chrome で、AI 連携とチャット欄の選択肢が「Claude Code」と3つのモデルだけになること（API キーが未設定のため、Claude API・Gemini API は出ない）、Sonnet 5.5（AI 連携の台本）と Haiku 5.5（チャット欄）を選んで保存できることを確かめ、設定は Opus 5.5 に戻した。型チェック・lint。
