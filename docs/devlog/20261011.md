# 2026-10-11 作業ログ

## AI 連携画面の作り直し
- 要件（ユーザー）: 全体を「API」と「API 以外」に分ける／AI ごとの説明文は不要／API キーは「名前・環境変数名・値」の枠と＋で追加（例: 「Claude API / ANTHROPIC_API_KEY / sk-ant-…」）／置き場所のセクションは不要。
- 実装:
  - `ApiKeyEntry`（名前と環境変数名）を追加。値は `.env.local` に保存し、DB には入れない。消すときは `.env.local` の行ごと消す（`removeEnvValues` を追加。前は空の値の行が残っていた）。
  - サービスが使っている環境変数（`YOUTUBE_…`・`INTERNAL_API_TOKEN` など）は、誤って上書きしないよう登録を拒否する。
  - `.env.local` に直接書いた ANTHROPIC_API_KEY / GEMINI_API_KEY も一覧に並べる（名前は AI の名前）。
  - 置き場所の設定（`AppSetting.claudeBinPath` / `antigravityBinPath`）は、画面と項目ごと消した（値はどちらも空だった）。
- 確認: 予約済みの変数名・形の正しくない変数名が拒否されること。テスト用のキーを追加 → 一覧に「…1234」で出る → 消す → 一覧と `.env.local` から消え、`.env.local` が試す前と同じ内容に戻ること（控えを取って比べ、控えは秘密情報を含むため消した）。画面のスクリーンショット。
