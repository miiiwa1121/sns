# 開発ログ一覧 (devlog)

日次の開発・調査・設計・意思決定の変遷を記録するディレクトリです。

## ルール
- ファイル名は `yyyymmdd.md` 形式で作成する。
- 同日中は同一ファイルに追記する。
- 実装・要件・設計・詰まった点・判断を変えた点・次にやることを具体的に記録する。
