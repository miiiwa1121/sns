# 開発ログ: 2026年10月8日

## 作業概要
YouTube、X (Twitter)、Instagram、TikTok への自律型マルチプラットフォーム動画投稿AIシステム「OmniPulse AI Studio」の要件定義、アーキテクチャ設計、ダッシュボード実装、およびマルチアカウント対応ローカルデータベース（SQLite + Prisma）の構築を実施。

---

## 作業詳細

### 1. プロジェクト立ち上げ & 要件定義
- **プロジェクト目的**: トレンドリサーチから長尺動画・切り抜きショート制作、各SNSへの投稿、アナリティクス分析・自律PDCAまでを一貫して行うAIアシスタントの構築。
- **フォーマット戦略**: YouTube向けの通常長尺動画（解説・ノウハウ）を主軸にしつつ、ハイライト部分を30〜60秒の縦型ショート動画（9:16）に自動切り抜きして、YouTube Shorts / TikTok / Instagram Reels / X にマルチ展開する方針を決定。
- **自律レベル**: 初期は人間がプレビューしてワンクリック承認できる「半自律・承認制（Human-in-Loop）」とし、完全自律（Auto-Pilot）への切り替えトグルを装備。

### 2. 技術スタックの比較とハイブリッド構成の決定
- フルスタック（Python FastAPI）とTypeScript中心（Next.js + Remotion）のメリット・デメリットを比較。
- React/CSSで高品質な動的字幕・アニメーションを作成でき、ブラウザ上でリアルタイムプレビュー可能な **Next.js + Remotion** をメイン基盤に選定。
- スタイリングは TailwindCSS を避け、柔軟性とデザイン制御性に優れた **Vanilla CSS (グラスモーフィズム・サイバーダーク)** で統一。

### 3. ダッシュボード・UIプロトタイプの構築
- 以下の5つの主要ビューを実装し、`http://localhost:3001` で稼働確認：
  1. **リサーチ & 企画 (ResearchView)**: トレンド一覧、Buzzスコア、AI推奨切り口
  2. **動画スタジオ (StudioView)**: 長尺台本チャプター、AI切り抜きショート、9:16スマホプレビューア
  3. **承認 & 配信 (ApprovalView)**: 各SNS別メタデータ編集、ワンクリック一括投稿
  4. **アナリティクス & PDCA (AnalyticsView)**: 各SNSメトリクス比較、CriticAI要因分析
  5. **エージェントアクティビティバー (AgentActivityTicker)**: リアルタイムログ

### 4. AI選定と実行環境の議論
- 端末スペックを調査: **Apple M5 (arm64), 16GB RAM**。
- ローカルLLM（Ollama: Qwen 2.5 7B等）とクラウドAPI（Gemini, Claude 3.7）のメリデメを整理。
- **課題判明**: ローカルLLMはPCスリープ時に停止し常時給電が必要になること、また無料枠クラウドAPIではレート制限や学習利用リスクにより本格的な商用運用には耐えられない点を確認。
- **方針決定**: まずは外部有料APIを契約する前に、**「半自律型（Antigravity / Gemini 3.8 Flash直接駆動）」**として各フェーズのAI頭脳を担い、0円で実際にプロジェクトのPDCAが回るか実証した上でAPI化・クラウド化を進める方針で合意。

### 5. データベース構築とマルチアカウント対応
- ユーザーより「AI・ITアカウントの運用」および「複数アカウント（マルチアカウント）運用前提の設計」「DB実体の確認」の要望を受け、インメモリ状態から永続化データベースへ刷新。
- **Prisma ORM (v6) + SQLite (`prisma/dev.db`)** を導入。
- マルチアカウント対応のスキーマ（`Account`, `PlatformConnection`, `Project`, `LongFormVideo`, `ShortClip`, `PublishLog`, `AnalyticsMetric`, `AgentKnowledge`）を定義・マイグレーション完了。
- 初期シードデータとして「AI速報スタジオ」および「ゼロから始めるITキャリア」の2アカウントを登録。
- ヘッダーにマルチアカウント切替セレクターおよびプロファイルバナー、新規チャンネル作成モーダルを追加。

  - **解決策**: 未使用のインポートを整理し、各SNSは独自カラードットや専用バッジで一貫したスタイルを適用。
